Lesson 0005 · 运动/滤波层

预测到命中时刻：状态、噪声与三种线性化

0004 给了带噪声的单板观测。这一节把车状态推到 t_hit：先看预测为什么会错，再看 EKF/ESKF/IEKF 各自修哪一类错。

预计 35 分钟先修：0001、0003、0004对应代码：target.cpp / motion_model.hpp / IESEKF_Double_Armor.hpp

本节结束时你能 写出状态转移和 P⁻ = FPFᵀ + Q；说出 EKF/IEKF/ESKF 各自修什么故障；解释三套代码的“世界系”为什么不同；用 NIS 判断预测和观测是否对得上。

1. 预测的第一步：状态怎么走

0004 讲清了观测：PnP 给的是单板位姿，不是车心。现在把自瞄真正要预测的车状态写成向量：

x = [ c, v, θ, ω, r1, r2, h ]

c⁻ = c + v·Δt
θ⁻ = θ + ω·Δt
R⁻ = R · Exp([0, 0, ω·Δt])      # wuhan 的 SO(3) 写法

协方差跟着走：

P⁻ = F P Fᵀ + Q
F = ∂f/∂x |_{x}

Q 是“模型没算到的那部分”。车会加速、会转向、会换板，这些都不在匀速模型里；Q 把它们折算成过程噪声。没有 Q，滤波器会越来越自信，最后对真实机动失去响应。

数值感受 目标在 4 m 处、横向速度 3 m/s，预测 0.15 s：横向走 0.45 m。一块小装甲板宽 0.135 m；如果瞄准当前位置，子弹到的时候已经偏了三个板宽。提前量不是“可选的优化”，是命中的前提。

这里的 t 不是随便取的未来时刻，而是 t_hit = t_now + latency + T_fly。预测到 t_hit 只是第一步；怎么把 T_fly 闭合，是 0006 的事。

2. 预测为什么会偏：三个具体故障

不要把 EKF/ESKF/IEKF 当成三种“高级程度”。它们分别对应三类具体的预测故障：

故障现象代码里的应对
角度绕圈θ 从 +π 跳到 −π，或 ω 很大时一步转过半圈sp/SHtech 用 limit_rad 把角度拉回；wuhan 直接用 SO(3)，不存 yaw 的标量
强非线性目标近、ω 大、单板斜视角，EKF 在 x⁻ 处线性化一次不够SHtech 用 IEKF/IESEKF 在迭代点反复线性化；wuhan 的 ESKF 也迭代 5 次
姿态不是单 yaw地面坡度、车体俯仰/横滚，单 yaw 模型把 roll/pitch 的误差吸收进 yawwuhan 估完整 rot_x/rot_y/rot_z；sp/SHtech 只估 yaw，靠安装/水平假设

先有故障，再有滤波器。反过来说：如果目标远、角速度小、观测噪声大，EKF 的一次线性化就够用，迭代只是浪费算力。

3. 三种滤波器，三种修法

EKF：在 x⁻ 处线性化一次

H = ∂h/∂x |_{x⁻}
K = P⁻Hᵀ(HP⁻Hᵀ + R)⁻¹
x⁺ = x⁻ + K(z - h(x⁻))

sp 用这种。优点是 H 可以解析、计算便宜；缺点是 h 弯得厉害时，残差会被映射到错误方向，P 也会被低估。

IEKF：在迭代点反复线性化

x_{k+1} = x_pri ⊕ K_k [ z - h(x_k) + H_k (x_k ⊖ x_pri) ]
K_k = P_pri H_kᵀ (H_k P_pri H_kᵀ + R)⁻¹

它来自对后验做高斯-牛顿。先验项 H_k(x_k ⊖ x_pri) 的作用，是把“当前迭代点相对先验的偏移”补回残差，保证迭代收敛到 MAP。

符号很容易写反 标准是 +H(x_k ⊖ x_pri)。SHtech 两处实现（IESEKF_Double_Armor.hpp:243、IESEKF.hpp:221）写成 +H(x_pri ⊖ x_k)，差一个负号。标量线性例子 x_pri=0, P=1, H=1, R=1, z=1：标准 IEKF 一步到 0.5 并停住；代码符号在 0.5 和 0 之间来回跳，5 次迭代落点还取决于奇偶。range-bearing 100 次实验末步 RMSE 因此到 23.21 m。

ESKF：把误差放到切空间

x = x̂ ⊕ δx

位置： c = ĉ + δc
姿态： R = R̂ · Exp(δθ)

预测： x̂⁻ = f(x̂),  P⁻ = F P Fᵀ + Q
更新： δ̂ = K(z - h(x̂)),  x̂ ← x̂ ⊕ δ̂

旋转矩阵不能直接加 δθ；ESKF 把姿态误差放在切空间，用右乘 R·Exp(δθ) 注入。这样 P 的旋转块不会被“旋转向量绕圈”污染。wuhan 用这种，代价是 H 通常要数值求，计算更重。

三套代码的对应关系：

项目滤波器线性化点H 怎么来代价
spEKFx⁻，一次解析链式法则最便宜；强非线性时偏
wuhanESKF误差状态，迭代 5 次误差坐标中心差分最贵；姿态一致性好
SHtechIESEKFx_k，迭代 5 次解析 H中等；实现符号要小心

4. 坐标系：预测必须在同一个世界系里

三套代码都叫“世界系”，但不是同一个惯性系：

sp:     世界原点在云台；速度是相对云台
SHtech: 世界原点在 IMU；速度是相对 IMU
wuhan:  世界原点在 odom；瞄准前减云台速度

底盘自己也在跑。如果预测用的是“目标相对世界”的速度，而控制用的是“目标相对云台”的角度，二者之间要减掉底盘/云台的运动；否则会有一个系统性的提前量偏差。

一个检查方法 把同一帧的目标位置分别投到 odom 和云台系，静止底盘时两个系只差一个固定变换；底盘一动，差的就是自身速度。预测前先问一句：这个速度是相对谁的？

5. Q/R 和 NIS：怎么知道预测可不可信

Q 管“模型有多不准”，R 管“观测有多不准”。它们共同决定 K 更信谁：

K = P⁻ / (P⁻ + R)          # 一维直觉
Q 大 → P⁻ 大 → K 大 → 更信观测
R 大 → K 小 → 更信预测

在自瞄里，Q 的来源是：目标加速、转向、换板、两帧之间的机动；R 的来源是：PnP 像素/深度、灯条端点、斜视角、15° 俯仰。把这两个来源分开，调参才有方向。

NIS 用来检查“残差和 S 是否对得上”：

y = z - h(x⁻)
S = H P⁻ Hᵀ + R
NIS = yᵀ S⁻¹ y          # 期望 ≈ m（观测维数）

sp 的代码里有一个阈值用法值得核对：0.711 是 χ²₄ 的 5% 下分位，不是 95% 上分位；用 NIS > 0.711 判失败，健康滤波器约 95% 的帧都会被判失败。具体见 0003 的阈值表。

SHtech 的双模型是一个很工程化的回答：低速时整车模型对“只平移不旋转”不敏感，容易把平移误估成旋转；高速时板模型又跟不上换板。用 |ω| 在 0.7/2.7 两个阈值之间切换，把“模型选择”显式化。
