# 协方差补充页的数值核验

脚本：`verify/verify_covariance.py`；图：`assets/figures/cov_product.png`、`cov_scatter.png`、`cov_ellipse_axes.png`、`cov_transform.png`。

## 1. 5 个点的手算

点：

```text
(1,2), (2,1), (3,4), (4,3), (5,5)
```

均值 `(3,3)`，偏差：

```text
dx = [-2, -1,  0,  1,  2]
dy = [-1, -2,  1,  0,  2]
dx·dy = [ 2,  2,  0,  0,  4]   和为 8
```

样本协方差（分母 `N−1=4`）：

```text
Cov(x,y) = 8/4 = 2.0
Var(x)   = 10/4 = 2.5
Var(y)   = 10/4 = 2.5
ρ        = 2.0/2.5 = 0.8
P        = [[2.5, 2.0], [2.0, 2.5]]
```

特征值 `[4.5, 0.5]`，轴长 `[2.1213, 0.7071]`，对应图 `cov_ellipse_axes.png`。

## 2. 为什么 `E[XY]−E[X]E[Y]` 是 1.6，而样本协方差是 2.0？

- `E[XY]−E[X]E[Y] = 1.6`：这是“除以 N”的总体/样本矩。
- 样本协方差 `8/4 = 2.0`：这是“除以 N−1”的无偏估计。

两者关系：`2.0 × (N−1)/N = 2.0 × 4/5 = 1.6`。N 很大时差别可忽略；小样本时要注意分母。

## 3. 线性变换

取 `A=[[1.4,0.9],[0.1,1.0]]`，20 万个 `N(0,I)` 样本做 `y=Ax`：

```text
A Aᵀ = [[2.77, 1.04],
        [1.04, 1.01]]
Monte Carlo Cov(Ax) = [[2.769992, 1.039810],
                       [1.039810, 1.007013]]
max |MC − A Aᵀ| = 0.002987
```

在 0.3% 以内，验证 `Cov(Ax)=A Cov(x) Aᵀ`。图 `cov_transform.png`。

## 4. 一维平移/缩放

对 `a=-2.5, b=7`：

```text
Var(aX+b) = 15.625
a² Var(X) = 15.625
```

平移 `b` 不影响方差；缩放 `a` 平方后进入方差。图 `cov_scatter.png`、`cov_product.png` 展示符号和“带符号面积”。

## 5. 对课程的结论

- 协方差的定义就是“偏差乘积的期望”；样本版本分母用 `N−1`。
- 协方差矩阵的对角线是方差，非对角线是协方差；它是对称、半正定的。
- 椭圆由 `P=VΛVᵀ` 决定：方向 `V`，轴长 `sqrt(λ)`。
- 线性变换 `y=Ax+b` 只让 `A` 改变形状：`P_y=A P_x Aᵀ`；`b` 只平移。
- KF 的 `P/Q/R` 都是协方差；一维后验 `1/P⁺=1/P⁻+1/R` 是“精度相加”。
