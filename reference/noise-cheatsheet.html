噪声、协方差与一致性

Q/R 不是“误差大小”，是“不确定性的形状”。这一页把三套代码里的噪声模型放在一起。

1. 协方差的几何

P = [[σx², ρσxσy],
     [ρσxσy, σy²]]

特征值 → 轴长²
特征向量 → 轴方向

对角阵 = 椭圆轴对齐坐标轴；非对角 = 有相关性，椭圆倾斜。

5. 调参直觉

现象可能原因动作
跟踪抖、容易被检测噪声带跑R 太小 / Q 太大增大 R 或减小 Q
响应慢、机动时跟不上R 太大 / Q 太小减小 R 或增大 Q
NIS 长期 > 上界P 太小 / R 太小 / 模型漏状态检查 Q、R、状态维数
NIS 长期 < 下界P 太大 / R 太大减小 Q/R，或检查是否过平滑
换板时位置跳数据关联错 / 车心模型错先查关联，再查 r/l/h
不要孤立调 Q 或 R KF 只关心 P/R 的相对大小。把 Q 和 R 同时放大 10 倍，稳态增益几乎不变，但瞬态会变。
