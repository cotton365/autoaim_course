推荐阅读顺序

  1. 先读 sp 的 Target::update + aimer.aim：最短的完整链路。
  2. 再读 wuhan 的 motion_model.hpp 的 armor_pose / UVLMeasure：理解“图像投影观测”。
  3. 再读 SHtech 的 Tracker::track + Planner::make_plan：理解“双模型 + 策略切换”。
  4. 最后读三家的弹道和开火门控，比较“预测层”和“控制层”的分工。
