KF / EKF / ESKF / IEKF

一页纸版本。符号与三套代码一致：x 状态、P 协方差、F 状态转移、Q 过程噪声、H 观测雅可比、R 观测噪声、K 增益、S 创新协方差。

1. 一维 KF

K  = P⁻ / (P⁻ + R)
μ⁺ = μ⁻ + K (z - μ⁻)
P⁺ = (1 - K) P⁻

等价于两个高斯相乘：1/P⁺ = 1/P⁻ + 1/R。

2. 多维 KF

预测： x⁻ = F x                 P⁻ = F P Fᵀ + Q
创新： y  = z - H x⁻            S  = H P⁻ Hᵀ + R
增益： K  = P⁻ Hᵀ S⁻¹
更新： x⁺ = x⁻ + K y             P⁺ = (I-KH)P⁻(I-KH)ᵀ + KRKᵀ
符号维度含义调大
Pn×n状态不确定性更信观测
Qn×n预测模型不确定性更信观测、更活
Rm×m观测不确定性更信预测、更稳
Kn×m残差→状态修正—

4. EKF / IEKF / ESKF

方法线性化更新适用
EKF在 x⁻ 一次x⁺=x⁻+K(z-h(x⁻))弱非线性、算力紧
IEKF在 x_k 迭代x_{k+1}=x_pri⊕K[z-h(x_k)+H(x_k⊖x_pri)]强非线性、观测维度低
ESKF误差状态切空间δ=K(z-h(x̂)), x̂←x̂⊕δ有 SO(3) 姿态
ESKF 注入：
  c ← c + δc
  R ← R · Exp(δθ)

ESKF 求差：
  δc = c1 - c2
  δθ = Log(R2ᵀ R1)

5. 一致性检验

NIS  = yᵀ S⁻¹ y          ~ χ²(m)
NEES = (x-x̂)ᵀ P⁻¹ (x-x̂)  ~ χ²(n)

χ²₄: 5% 下分位 0.711, 95% 上分位 9.488, 均值 4
χ²₂: 95% 上分位 5.991
χ²₁: 95% 上分位 3.841
常见错误 把 0.711 当“95% 上界”。它是 4 自由度卡方的 5% 下分位；健康滤波器的 NIS 有 95% 的概率大于它。

7. 协方差复习

Cov(X,Y) = E[(X−EX)(Y−EY)] = E[XY] − EX·EY
P = E[(x−μ)(x−μ)ᵀ]
  = [[Var(X), Cov(X,Y)],
     [Cov(X,Y), Var(Y)]]
P = VΛVᵀ，椭圆轴长 = sqrt(λ)
y = Ax + b → Cov(y) = A P Aᵀ

完整推导（从高中期望/方差讲起）：协方差补充页。
